# M3-05 列表基础功能测试

这是任务列表的第一笔前端交付，不代表 M3-05 的提交/详情接通或 M3 的真实调度验收完成。任务 HTTP 尚未发布，隔离测试使用生成的共享契约样例；产品不包含 mock 数据或测试开关。

## 1. 推荐先运行自动检查

在仓库根目录打开终端：

```powershell
cd frontend
npm ci
npm test
npm run build
```

如果终端位于外层“云计算/大作业”目录，先运行 `cd .\LLMCloud\frontend`，无需再执行 `cd frontend`。Windows 若提示 npm.ps1 的执行策略错误，使用 `npm.cmd` 代替 `npm`；不需要更改系统执行策略。

只运行本次新增的请求与轮询测试：

```powershell
node --test tests/tasks.test.mjs tests/task-polling.test.mjs
```

预期所有检查通过，fail 为 0，生产构建生成 dist。无需 API、Redis、数据库、GPU 或浏览器；测试不修改实际业务数据。

| 检查           | 自动验证内容                                                                |
| -------------- | --------------------------------------------------------------------------- |
| 查询参数       | ALL 省略 status；五状态使用 status；page_size=20                            |
| 筛选/分页      | 切换状态回第一页，翻页、手动刷新、全局服务刷新、轮询保留筛选                |
| 连续操作       | 加载期间继续切换状态/翻页，新请求不被丢弃                                   |
| 乱序响应       | 旧成功、失败与 finally 不能覆盖新的数据、错误或 loading                     |
| 轮询           | 前一轮完成后等待 2 秒，不重叠；手动请求优先；隐藏/停止/重启不生成重复计时器 |
| 取消与能力变化 | 取消后旧响应不能写回；API 能力消失后不恢复旧数据                            |
| 列表呈现       | 空结果 0 / 0 且分页禁用；越界空页保留原页；加载、空结果和错误分别显示       |
| 契约边界       | 无效分页响应报错，不补造字段、不回退假数据；API 不可用时按钮禁用            |

延迟 fetch 替身会故意忽略 abort，检查请求序号仍能拦截旧成功/失败。测试直接调用 workspace.js 的真实请求函数；轮询使用 TasksPanel 实际导入的调度器，未复制一份业务逻辑。

## 2. 当前可以手动检查什么

```powershell
npm run dev
```

打开 http://127.0.0.1:5173/#tasks 。应看到“全部、待派发、排队中、训练中、已完成、失败”六个入口。当前后端未发布任务接口，筛选与刷新禁用、显示等待服务是预期行为；不能仅靠此页面验证成功的任务查询。可以切换页面确认原有布局和数据集功能保留。

## 3. M3-03 任务 API 接入后的浏览器验收

在独立测试环境中使用已有任务记录，打开开发者工具 Network，筛选 tasks 请求。以下步骤仍待真实 API/浏览器联调，当前不记为已通过。

1. 点击“全部”：请求含 page=1、page_size=20，不含 status。
2. 点击“训练中”：请求含 status=RUNNING、page=1、page_size=20。页面总数应为后端筛选后的 total。
3. 存在多页时翻到第二页：请求保留 status=RUNNING、page=2；点刷新并等待轮询，查询参数不变。
4. 在第二页切到“失败”：请求变为 status=FAILED、page=1；待派发/排队中/已完成同理。
5. 开启 Network Slow 3G，快速切换状态或连续翻页：旧请求可能显示取消，最终页面应与最后一次选择一致，不能出现旧错误或提前结束 loading。
6. 关闭“每 2 秒刷新”：等待至少 5 秒，不应产生新的自动查询；重新勾选后恢复。隐藏浏览器标签页时暂停，返回后恢复；离开训练任务页面后不再轮询任务。
7. 使用空结果：显示 0 / 0，上一页/下一页禁用。若服务端数据变化使原页越界，显示“当前页没有任务”，保留页码并允许返回上一页。
8. 在 Network 中阻止 tasks 请求：显示错误而非“没有任务”；恢复网络后点刷新，筛选与页码保持不变并恢复列表。

原有 M1 浏览器回归仍使用 `npm run test:e2e`（19 项数据集场景，需既有 uv/Chromium 环境）；它不等于本次任务列表已完成真实端到端验收。

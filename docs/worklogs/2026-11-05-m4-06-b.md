## 真实服务与替身的边界

新入口直接调用原 create_app，使用正式 TaskService/SqlTaskRepository、TaskObservabilityService、TaskDownloadService 和 AdapterResponse。每次服务进程使用独立 TemporaryDirectory/SQLite/数据/日志/输出；测试控制仅在该可执行入口安装，不向产品添加路由、开关或假数据。不复制 SQL、文件安全读取、指标解析、ZIP 打包或原产物审计算法。

Publisher 复用既有测试替身；执行事件通过原 MetricWriter 写文件并回调正式 record_progress。状态通过 claim/record_progress/complete/fail 改变。可下载 bundle 复用 tests/worker_support.synthetic_train 与原独立 CPU 审计，不加载模型或调用 GPU。大分页观测场景仅提交合成完成元数据，没有有效 Adapter；不把该场景的 COMPLETED 当作 bundle 证据。另有独立下载场景验证有效/无效产物。

下载 body 暂停为测试进程 ASGI send 层明确注入：原服务已核对/准备 ZIP，真实响应头和前 4 字节实际发出，剩余 body 等待，随后由实际浏览器取消/切任务触发 TCP 断开。没有伪造下载端点或直接调用清理替代断连。原 AdapterResponse 的 receive watcher/finally 实际释放临时目录与槽位，测试同时核对外层退出计数、目录为空、下一任务可以再次下载。

本机无 Ubuntu WSL，仅有 Docker Desktop 发行版。使用已缓存 ghcr.io/astral-sh/uv:python3.12-bookworm-slim 创建一次性 CPU 容器；仓库只读挂载，uv 的锁定服务/dev 依赖和所有业务测试数据位于容器 /tmp，只转发 127.0.0.1:18006。Windows Playwright headless Chromium 通过 Vite 代理访问容器实际 API。依赖同步 uv sync --locked，无训练 extra；测试每项均确认服务未导入 torch/numpy/transformers/peft。正式 Linux 文件安全原语未打补丁。

## 六项实际浏览器矩阵

| 场景 | 实际检查与结果 |
| --- | --- |
| 指标/终态 | 从真实 not_created 到 1002 条记录积压；暂停轮询准备积压后，手动单轮恰取五页 1000 条并提示余量，下一轮补齐；再恢复自动轮询追加到 600 个 train + 600 个 eval，同 step 两类均保留。最终 train Loss=0，尾部 eval 不覆盖它；TaskDetail 完成后补齐最后指标/日志，再观察完整轮询间隔无新读取。桌面/390px 无页面横向溢出。 |
| 半行/来源/损坏 | 实际文件半行不推进有效点，补换行后出现新点；原子替换文件后真实 409/METRICS_CURSOR_INVALID 使 UI 重置并重读。坏完整 JSON 行返回 METRICS_CORRUPTED，UI 保留已读点；真实 fail 后仍显示业务失败原因及禁用下载。 |
| 日志 | 105 条实际 JSONL 与尾部半行产生 truncated/tail_incomplete/filtered_lines 三类提示；原投影去掉 HTML/自由字段，不泄漏 private-path。曾读文件删除或替换为越界符号链接时返回 LOGS_UNAVAILABLE，页面保留先前可用快照；不伪装为空日志。 |
| 下载成功/门禁 | PENDING/QUEUED/RUNNING/FAILED 返回 409，COMPLETED 有效 bundle 返回 200 ZIP。实际浏览器规范 UUID 文件名与落盘字节，独立解压/CRC/原 verify_training_artifacts 及与源 manifest 哈希一致；长度、MIME、Cache-Control、CORS 公开头及运行时三个 OpenAPI 路径一致；未知任务 404、额外路径参数 422。 |
| 下载失败 | 持有真实准备槽位触发 429/Retry-After=2；页面展示服务端说明、请求编号和手动重试。权重同长度篡改返回 INVALID_ARTIFACT，SQL 仍 COMPLETED；声明大小预算超限返回 413（仅元数据故障，不分配 256 MiB）；downloads 工作区可写权限过宽返回 STORAGE_UNAVAILABLE，并恢复测试权限。失败后无临时目录残留。 |
| 下载取消/切换 | 实际 body 未结束时取消及切任务，浏览器不保存旧文件，TCP 断开、原响应清理及槽位释放均通过；取消后另一 UUID 的真实 ZIP 可以再次保存，名称正确。 |

浏览器响应没有 route 拦截，错误码/真实状态码/请求编号取自实际 HTTP。原 ErrorNotice 展示服务端 message/request_id，并不保证正文展示 code，因此测试分别核对网络 code 与 UI message/request_id，不为迁就断言修改产品。

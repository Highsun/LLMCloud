# 删除 GitHub Actions workflow

日期：2026-11-06。起点 main=10114a7。用户收到多次 workflow 失败邮件，先要求停止非必要运行，随后明确要求直接删除仓库 workflow，不保留手动入口。

检查发现仓库只有 `.github/workflows/ci.yml`，原先每次 push/PR 自动执行 CPU/HTTP/浏览器检查；日常提交因此也会触发。训练实验在本机执行，远端 Actions 不是项目运行或本机验收的必要条件。本次未排查或断言历史各次失败原因。

删除唯一 workflow。AGENTS/README 明确本机验证，未经用户要求不得重新添加 workflow、启动或重跑 Actions。不修改训练/后端/前端逻辑，不使用 Actions 验证删除操作。历史 CI 日志保留当时事实，不重写历史结果。

开始任务时已 fetch 核对主线，没有新增队友交付；提交前 fetch 的自动权限审核连续超时、未执行，最新远端状态尚未再次确认；提交/推送以最终实际 Git 结果为准，不强推消除差异。验证已确认实际目录不再含 workflow，Git diff 无空白错误；无需训练、安装依赖或全量业务回归。本次不操作历史运行记录，也不声称已取消在途运行。

- training_summary 为持久化既有 complete(summary) 参数补充的内部 JSON 列；celery_task_id 收敛为非空 String(255)。不改变 Worker Protocol 或公开 DTO/生成 Schema，结构升级由显式迁移负责。
- services/task_records：创建请求规范 SHA-256、记录/响应/执行快照一致性验证；校验可疑或损坏存量记录，不能把损坏当作不存在或重复消息跳过。
- SqlTaskRepository(sessions)：五个 Worker 方法；create/get_detail/list；mark_queued/mark_dispatch_failed/mark_dispatch_uncertain。每次独立 Session，SQLite 显式读事务保证 count/page 同一快照，BEGIN IMMEDIATE 序列化短写事务，状态/领取/token 再以 SQL 条件约束；不在事务中联网/读模型/训练/审计文件。
- 创建只读取 Dataset 元数据，生成独立业务 ID/消息 ID；可选同键同规范请求回原 TaskCreation(created=False)，不同请求冲突，无键允许独立创建。完整唯一索引作为数据库约束，部分索引不能冒充。
- 回调仅 train 推进，重复/旧步数和 eval 保持归属时返回 True 而不推进；固定总步数/内部步数上限，失败保留进度，终态拒绝晚到更新。有效产物完成提交失败不会触发仓储自动 fail；get_status 新事务可读真实状态，Worker 负责后续决定。
- core/task_migration + scripts/migrate_tasks.py：默认只读 check、显式 apply、SQLite WAL 一致备份（0600）、加写锁复查、事务替换并保留主外键/索引、失败回滚。启动在 create_all 前检查旧任务结构，禁止自动升级/删库。
- 非空旧表要求可信 revision/runtime/必要消息 ID；数据文件复用扫描器核对摘要/统计；旧 FAILED 要安全错误映射；旧 RUNNING 默认阻塞，仅显式离线中断处置才结束为 WORKER_INTERRUPTED，不伪造 owner；旧 COMPLETED 调用共享真实审计器并比对快照。未知表扩展/触发器/相关视图、遗留 staging、损坏记录均不覆盖。

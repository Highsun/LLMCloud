## 生产实现

- 独立观测控制器通过注入的原 request/supports 消费真实 API；保存当前任务的 source_id/cursor、有限点集、最新 train、指标/日志各自错误/加载/结束状态。切任务清理旧状态，隐藏/离开/关闭取消请求；generation 隔离旧成功、错误和 finally，传输不响应 abort 也不能污染新选择。
- 指标仅请求 cursor/source_id/limit，不再发送 after_step。记录按 source_id/offset 合并，train/eval 相同步均保留；游标原样使用服务端 next_cursor，不从 step、记录数或浏览器 JSON 重编码猜算。类型、字段、身份、版本、游标、跨页步数/kind 顺序、总步数及有限值均校验；非法整页报 INVALID_RESPONSE，不推进游标、不丢已有点。
- 每轮最多 5 页、每页 200；has_more 在后续有界轮次继续，并显示补拉状态。点集最多保留最近 10000 条，游标和跨页校验的最后记录独立保存，裁剪有明确窗口提示；最新 train 单独保存，末尾 eval 或裁剪不覆盖它。409/METRICS_CURSOR_INVALID 每轮最多重置一次，清除旧源数据后重新读取，重复失效显示错误，不在本轮无限重试。
- 任务列表/详情与观测使用各自周期；详情不等待指标请求结束才释放 loading，列表请求迟缓不阻止观测周期启动。TaskDetail 是业务来源，观测 task_status 不覆盖它；COMPLETED/FAILED 后仍分轮读完指标，再取一次最终日志，取齐才停止自动观测。迟到 RUNNING 不能提前宣布最终快照取齐。自动刷新关闭时允许显式单轮手动读取。
- 日志严格消费 LogsPage，保留 source_state、truncated、tail_incomplete、filtered_lines，尾部快照替换而非拼接；三类提示、自然未产出、现存空文件、终态无记录及读取错误各自显示。错误保留旧可用快照，两个观测接口失败均不写任务状态。日志模板始终文本插值，含 HTML 的内容不会执行；历史滚动位置不被刷新拉到底，提供回到底部。切换任务重新创建日志组件。
- 页面保留原五状态筛选/分页、配置/失败码、100% RUNNING 保存等待语义和能力探测；新增独立刷新指标/日志按钮，最新训练 Loss 卡片只读 train。下载按钮及原 helper 未在本轮修复，05 的固定身份/MIME/完整 blob 取消与超时差异仍保留。

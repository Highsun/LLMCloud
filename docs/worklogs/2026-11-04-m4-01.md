## 类型边界与本次明确的细节

CPU 类型验证结构，不检查数据库完成、当前行边界/源文件身份/路径权限、文件读取预算或完整产物。MetricsPage 可从 eval 开始，SQL 状态可暂落后文件指标；空终态页可有非零 cursor。响应不接受查询参数的宽松字符串格式；查询只接受 ASCII 十进制整数文本，原始重复查询项仍由未来 HTTP 适配层拒绝。

日志先在 64 KiB 窗口选最后 tail 个完整源行再投影，不因过滤补足旧行；filtered_lines 按被丢弃/修改的选中记录计一次，不大于 tail，类型全局最大 500。failure 不透传自由文本 message，说明从 TaskDetail 取得。字段白名单还必须由 02 实现类型/标识符检查，不能只根据键名信任原内容。生成样例没有来源于真实任务的日志或数据正文。

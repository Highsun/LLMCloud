## 4. 下载后独立 CPU 审计

下载位置由实际浏览器操作者记录。B 使用自己的浏览器直连时，原 ZIP 保留在 B 本机；A 需接收这份实际浏览器下载用于源文件对比时，私下交接并核对 SHA-256，不能用服务器另一份 ZIP 代替。

1. 用 PowerShell `Get-FileHash -Algorithm SHA256 -LiteralPath '<实际ZIP绝对路径>'` 与 `Get-Item -LiteralPath '<实际ZIP绝对路径>'` 记录 SHA-256/长度；占位路径替换后才能执行。
2. 对每份 ZIP 使用全新的隔离目录：`<audit-data>/outputs/<task_id>/...`。ZIP 已自带 UUID 顶层，应解压到 `outputs`，避免嵌套两层 UUID。不要解压到原训练目录或覆盖另一份下载。解压前检查成员路径；A 可用既有 `scripts.m4_acceptance_support.audit_download` 做限量安全解压、原审计及源文件比较。
3. 在项目根目录的独立 CPU 环境执行以下模板（实际 data-dir 使用绝对路径；训练环境不能通过基础同步裁剪 training extra）：

```text
uv run --locked python scripts/check_training_artifacts.py --task-id <实际UUID> --data-dir <audit-data绝对路径> --revision 7ae557604adf67be50417f59c2c2f167def9a775
```

4. 保存命令、stdout/stderr、退出码。退出码 0 才记原 CPU 审计通过；该审计不要求 GPU，也不代表已做重载生成或效果提升。

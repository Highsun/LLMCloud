## 录制前检查

1. 冻结演示提交并记录 SHA；核对工作区，避免录制途中改依赖或拉取代码。
2. 使用 E 盘独立运行根目录，确认磁盘空间、模型缓存完整、GPU 空闲、Worker 唯一。数据、DB、Adapter 和原始录像均留 E 盘。
3. 先跑一遍短流程，检查端口、同源代理、账号会话、数据归属和推理模式。不能以录制前彩排代替保留正式证据。
4. 打开页面时隐藏浏览器个人资料与通知，使用专用演示账号。截图仅保留已脱敏内容。
5. 正式录制采用新目录，场记包含本地/云端、系统与 GPU、开始结束时间、提交、task_id 和片段文件 SHA-256。

## 失败与剪辑规则

网络或 GPU 故障时保留实际错误，停止当前片段并记录。可以切换到注明日期、环境和任务身份的历史真实片段，口播必须说明回放来源。不得用静态图动画伪装真实操作，不把 CPU 替身测试录成模型生成。

使用跳切压缩等待时保留提交前和终态后的 task_id，屏幕叠字说明省略等待。原始无剪辑录像与剪辑工程留 E 盘；课程视频导出和素材索引单独计算摘要，源录像不纳入 Git。涉及实际 90 秒服务端超时和 120 秒浏览器超时时，可在成片加速，必须在旁白与字幕写明加速倍率。
